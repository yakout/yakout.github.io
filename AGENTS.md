# AI Agent Instructions

- **Do NOT push** any changes to remote repositories without explicit approval from the user.
- **NEVER run `git add .` blindly.** Always verify `git status` first to ensure no unintended files (like `_site/`, `vendor/`, or `.DS_Store`) are being staged.
- **Check `.gitignore`** if untracked files appear in `git status` that should not be committed.
- Always follow the project's established conventions and style.
- Verify changes with existing tests and linting tools.
